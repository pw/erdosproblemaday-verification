                      Counterexamples to Erdős Problem 341
                                                    Zhiheng Li


                                                   Abstract
         Erdős problem 341 asks whether the consecutive gap sequence of the pair-sum-avoiding greedy
      extension of every finite seed set is eventually periodic. We give a negative answer by exhibiting
      the following counterexample
                  A = {1, 2, 3, 5, 7, 13, 22, 27, 28, 32, 36, 40, 47, 48, 52, 63, 71, 77, 81, 89, 97}.
      The proof constructs an infinite set S satisfying the exact greedy recurrence t ∈ S ⇐⇒ t ∈
                                                                                               / S +S
      for t > 97. We show that S is the greedy extension of the 21-element seed set A, and use a
      scale-eight sumset controller embedded in three residue classes modulo 49 and a finite modular
      shield to prove that the consecutive gap sequence of S is not eventually periodic. Motivated
      by this counterexample, we further obtain an infinite family of counterexamples by a slight
      modification of the construction.

1    Introduction and the main theorem
Write N = {1, 2, 3, . . .} and N0 = {0, 1, 2, . . .}. For X, Y ⊆ N0 and c ∈ N0 , put
        X + Y = {x + y | x ∈ X, y ∈ Y },                c + X = {c + x | x ∈ X},                X c = N0 \ X.
Equal summands are allowed in every sumset. For integers a ≤ b, write [a, b]Z = {a, a + 1, . . . , b}.
   Let A = {a1 < · · · < ak } ⊆ N be a nonempty finite set. For n ≥ k, define
                  an+1 = min{t ∈ N | t > an , t ∈
                                                / An + An },                  An = {a1 , . . . , an }.          (1)
Let dm = am+1 − am denote the consecutive gaps. Erdős and Graham asked whether, for every finite
initial set A, the resulting gap sequence (dm )m≥1 is eventually periodic. The question appears in
Erdős and Graham [1, p. 53] and is catalogued as Erdős Problem 341 in Bloom’s online database [2].
Related periodicity criteria are due to Calkin and Finch [3], while Calkin and Erdős [4] proved that
a natural class of aperiodic sum-free sets is incomplete. We answer the arbitrary finite-seed question
negatively.
Theorem 1.1. Let
               A = {1, 2, 3, 5, 7, 13, 22, 27, 28, 32, 36, 40, 47, 48, 52, 63, 71, 77, 81, 89, 97}.
For the sequence generated from A by (1),
                                  ∀K ≥ 1 ∀h ≥ 1 ∃m ≥ K               dm+h ̸= dm .
Thus its consecutive gap sequence is not eventually periodic.

Lemma 1.2 (Exact recurrence implies the greedy rule). Let S ⊆ N be infinite, let N ∈ S, and put
A = S ∩ [1, N ]Z . Suppose that

                                t∈S         ⇐⇒       t∈
                                                      / S+S           (t > N ).                     (2)

Then the increasing enumeration of S is exactly the greedy extension of A.
Proof. Scan the integers t > N in order. Inductively, immediately before testing t, the selected set
is S ∩ [1, t − 1]Z . Since all elements of S are positive, every representation t = u + v with u, v ∈ S
has u, v < t, and hence

                     t ∈ (S ∩ [1, t − 1]Z ) + (S ∩ [1, t − 1]Z )       ⇐⇒       t ∈ S + S.

Thus (2) makes the rule select exactly the elements of S, completing the induction.

Lemma 2.2. The membership indicator of Y0 is not ultimately periodic.

Proof. Suppose that there are N ≥ 0 and h ≥ 1 such that

                                   n ∈ Y0 ⇐⇒ n + h ∈ Y0             (n ≥ N ).

Choose a = 8k > max{N, h} and put m = 4a − h. Then N < a ≤ m ≤ 4a − 1. Hence m ∈ L, so

3      A finite shield modulo 49
All residues in this section lie in Z/49Z and are represented in {0, . . . , 48}. Put

    P = {7, 14, 28},      B = {3, 22, 32, 40, 48},        D = {1, 2, 5, 13, 27, 36, 47},   Q = P ∪ B. (15)

                                         (B + B) ∪ (P + B) ∪ (D + B) = Z/49Z \ Q,                     (16)

                           7 + 7 = 14,       14 + 14 = 28,         28 + 28 = 49 + 7.                  (19)

Proof. All assertions follow by direct computation in Z/49Z.

Theorem 3.2. For every t > 97,

                                         t∈S         ⇐⇒     t∈

Proof. Write t = 49q + r, with 0 ≤ r < 49. Since t > 97, we have q ≥ 2.
   First let r ∈ Q = B ∪ P . The six possible pair-sum types are

                         D + D,     D + B,    D + P,       B + B,     B + P,     P + P.

A D + D sum is at most 94 < t. Equation (17) excludes the next four types from Q, while (18)

                                  49q + 14 ∈ S + S ⇐⇒ q ∈ Y0 + Y0 ,
                                  49q + 28 ∈ S + S ⇐⇒ q ∈ Y1 + Y1 ,
                                   49q + 7 ∈ S + S ⇐⇒ q − 1 ∈ Y2 + Y2 .

Indeed, the corresponding representations are

                              (49u + 7) + (49v + 7) = 49(u + v) + 14,
                            (49u + 14) + (49v + 14) = 49(u + v) + 28,
                            (49u + 28) + (49v + 28) = 49(u + v + 1) + 7.

The exclusion of every other source type proves the converse implication in each equivalence. The
controller identities (9)–(11) therefore make every P -rail integer represented exactly when it is
absent from S. Every B-rail integer belongs to S, and the same exhaustive source analysis shows
that none is represented. Thus (22) holds for r ∈ Q.
   Now let r ∈/ Q. Such an integer t is not in S: its residue excludes every infinite rail, and t > 97
excludes the finite set D. By (16), there exist b ∈ B and x ∈ B ∪ D ∪ P such that x + b ≡ r
(mod 49). Set

             ex = x    (x ∈ B ∪ D),      e7 = 7,        e14 = 63 = 49 + 14,      e28 = 28.

Every ex belongs to S. Write

                                ex = 49ux + x,          x + b = 49c + r.

Here ux , c ∈ {0, 1}. Since q ≥ 2, the quotient q − ux − c is nonnegative, and
                                                              
                               t = ex + 49(q − ux − c) + b ∈ S + S.

The second summand is a positive element of a full B-rail. Both summands are positive and sum to
t, so each is smaller than t. This completes the proof.

   By (21), Theorem 3.2, and Lemma 1.2, the increasing enumeration of S is exactly the greedy
extension of the seed A in Theorem 1.1.


4    Nonperiodicity of the gaps
Lemma 4.1. Let T = {t1 < t2 < · · · } ⊆ N be infinite. If the consecutive gaps tm+1 − tm are
eventually periodic, then the membership indicator of T is ultimately periodic.

Proof. Suppose that the gaps have period h ≥ 1 from index K onward. Let
                                         h−1
                                         X
                                   H=          (tK+j+1 − tK+j ) > 0.
                                         j=0

Every block of h consecutive gaps in the periodic tail has sum H, so tm+h = tm + H for m ≥ K.
Since T is infinite, it is unbounded. Thus, given n ≥ tK , there is a unique m ≥ K such that
tm ≤ n < tm+1 , and

                      tm+h ≤ n + H < tm+h+1 ,           (n + H) − tm+h = n − tm .

Thus n = tm if and only if n + H = tm+h , which proves

                               n ∈ T ⇐⇒ n + H ∈ T              (n ≥ tK ).

This is ultimate periodicity of the membership indicator.

Proof of Theorem 1.1. The residue-7 rail of S satisfies

                              49q + 7 ∈ S     ⇐⇒        q ∈ Y0       (q ∈ N0 ).                    (23)

Suppose, for contradiction, that membership in S were ultimately periodic with period h ≥ 1. Then
49h would also be an ultimate period. For all sufficiently large q, equation (23) would give

                q ∈ Y0 ⇐⇒ 49q + 7 ∈ S ⇐⇒ 49(q + h) + 7 ∈ S ⇐⇒ q + h ∈ Y0 ,

contradicting Lemma 2.2. Thus the membership indicator of S is not ultimately periodic. The
contrapositive of Lemma 4.1 now shows that the consecutive gaps in the increasing enumeration of
S are not eventually periodic, which is the assertion of the theorem.


5    An infinite family of counterexamples
We further give an infinite family of counterexamples by replacing the finite shield above with a
parameterized family of finite shields.
   Fix an integer p ≥ 18, put M = 7p, and work in Z/M Z, represented by {0, . . . , M − 1}. Define

               Pp = {p, 2p, 4p},      Bp = {M − 3, M − 1, 6p + 3},                Qp = Pp ∪ Bp ,
                                                                                                   (24)
                      Fp = Qp ∪ (Qp − Bp ) ∪ (Qp − Pp ),            Dp = Z/M Z \ Fp ,

where Qp − Bp = {q − b : q ∈ Qp , b ∈ Bp }, and similarly for Qp − Pp . Set

                        Ap = Dp ∪ Bp ∪ (M + Bp ) ∪ {p, 4p, M + 2p, M + 4p}.                        (25)

Theorem 5.1. For every integer p ≥ 18, the seed Ap in (25) has 7p − 20 elements. For the sequence
generated from Ap by (1),

                                ∀K ≥ 1 ∀h ≥ 1 ∃m ≥ K             dm+h ̸= dm .

Thus its consecutive-gap sequence is not eventually periodic. In particular, the sets Ap , p ≥ 18, form
an infinite family of counterexamples.
    All residues in this section lie in Z/M Z, with the notation of (24).
Lemma 5.2 (Uniform finite shield). In Z/M Z, for every p ≥ 18,

                                                                    Dp + Bp = Z/M Z \ Qp ,         (26)

               Qp ∩ (Bp + Bp ) ∪ (Pp + Bp ) ∪ (Dp + Bp ) ∪ (Dp + Pp ) = ∅,                         (27)
                                                           (Pp + Pp ) ∩ Qp = Pp .                  (28)

Moreover, the only ordered pairs in Pp × Pp whose sum lies in Qp are

                        p + p = 2p,       2p + 2p = 4p,           4p + 4p = M + p.                 (29)

Proof. Expanding the definition in (24) gives

               Fp = {0, 2, p − 6, p − 4, p, p + 1, p + 3, 2p − 3, 2p, 2p + 1, 2p + 3,

                      5p − 3, 5p − 1, 5p, 5p + 3,
                      6p − 3, 6p − 1, 6p, 6p + 3, 6p + 4, 6p + 6, M − 3, M − 2, M − 1}.

                                 d + b = Mc + r      (c ∈ {0, 1}).

Proof of Theorem 5.1. Equation (34) proves the asserted cardinality. The proof of nonperiodicity
is the same as in Theorem 1.1. Indeed, suppose, for contradiction, that membership in Sp were
ultimately periodic with period h ≥ 1. Then for all sufficiently large q,

              q ∈ Y0 ⇐⇒ M q + p ∈ Sp ⇐⇒ M (q + h) + p ∈ Sp ⇐⇒ q + h ∈ Y0 ,

contradicting Lemma 2.2. Lemma 4.1 therefore shows that the consecutive gaps in the greedy
extension of Ap are not eventually periodic.
