This publication copy makes documentation and packaging corrections found by
two hostile audits.  It does not change the proof source, binaries, frozen
cube logs, witnesses, OEIS input, or search counters.

1. The README now says explicitly that the upper proof uses every published
   prefix value `a(1),...,a(68)`, not only `a(68)=32`.
2. The orphaned `audit_model.log` was removed because its generating source
   and solver inputs were not present.  It was auxiliary and is not called by
   `reproduce.sh` or used by the DFS certificate.
3. Both independent hostile-audit reports were added.
4. The source comment above `clique_cover_bound` should be read with this
   qualification: when the routine returns as soon as its running clique
   count reaches `needed`, that value is a safe no-prune sentinel, not a
   completed partition bound.  The caller prunes only when the routine
   finishes the full partition and returns a value below `needed`; both
   audits checked this control flow.  The audited source was left byte-for-byte
   unchanged so its recorded source and binary hashes remain meaningful.

`reproduce.sh` regenerates the core certificate checks.  Some additional
historical cross-check logs are frozen, checksummed evidence rather than
outputs regenerated by the fast script; the README labels the full
seven-cube rerun separately as `FULL=1 ./reproduce.sh`.
