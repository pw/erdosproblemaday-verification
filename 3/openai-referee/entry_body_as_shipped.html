The problem (erdosproblems.com/3; Erdős, from 1974 on, in at least fifteen of his problem papers; $5000, the largest prize on the site). If A ⊆ ℕ has Σa∈A 1/a = ∞, must A contain arbitrarily long arithmetic progressions? Writing rk(N) for the largest subset of {1, …, N} with no nonconstant k-term progression, the question is equivalent to a bound on rk(N) that is summable over dyadic scales — Σm rk(2m)/2m < ∞ — which N/(log N)1+c gives and N/log N does not. Bloom and Sisask crossed that threshold for k = 3 in 2020; for every k ≥ 4 the record before this release was Leng, Sah and Sawhney (2024), rk(N) ≪ N exp(−(log log N)ck) with ck < 1, which is not summable. So the question was open for every length from four up.

What OpenAI's 6 October release claims, in three different strengths — keep them apart. (1) The paper ("Quasipolynomial Bounds for Arithmetic Progressions", dated 23 September 2026, 198 pages, family 159 of the release; sha256 481eaf77…c59be in our bundle) claims Theorem 1.1: for each fixed k ≥ 3 there are Ck, ck, εk > 0 with rk(N) ≤ Ck N exp(−ck (log N)εk) for all N ≥ 2 — a stretched-exponential saving in log N for every length, the shape Kelley and Meka reached for k = 3 in 2023, now for all k. (2) Its Corollary 1.2 is Erdős's statement, by the five-line dyadic summation above. (3) The Lean in the release proves neither (1) nor only (2). The Comparator challenge ComparatorChallenges/ErdosReciprocal.lean states exactly the question on the problem page — ∀ A : Set ℕ, ¬ Summable (reciprocalTerm A) → ∀ k : ℕ, HasAP A k, with HasAP A k := ∃ a d : ℕ, 0 < d ∧ ∀ i < k, a + i * d ∈ A — and the solution module Results/Conclusions.lean proves it as the second half of manuscript_main_theorems : QuantitativeDensityTheorem ∧ ReciprocalProgressionTheorem, where the first half is ∀ k ≥ 3, ∃ C c η > 0, ∀ N ≥ 3, extremalNumber k N ≤ C · N · exp(−c · (log log N)^(1+η)). That is weaker than Theorem 1.1 but strictly past the summability threshold — the exponent on log log N is 1 + η where Leng–Sah–Sawhney had ck < 1 — so if a kernel accepts it, the formal object is itself a new bound for every k ≥ 4 and settles #3 on its own, independently of the 198 pages. Thomas Bloom read the same thing on 8 October ("the Comparator Challenge Lean file has only the statement of Erdős' conjecture … the actual Lean code appears to prove the weaker bound exp(−(log log N)1+ck)N"); OpenAI's own docs/159.md says "the selected theorem is the reciprocal-sum consequence; the paper's quantitative upper bound … is outside this statement". OpenAI's own catalogue of "papers with a formalized main result" (lean/formalization.yaml, 185 of the release's 405 Comparator challenges) does not list this one — consistently, since the formalized theorem is the corollary and not the paper's main result — while the release's CONTENTS.md puts its "Lean" link beside the quasipolynomial bound, which the Lean does not prove.
