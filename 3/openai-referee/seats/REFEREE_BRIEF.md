## What is claimed
Theorem 1.1: for each fixed k ≥ 3 there are C_k, c_k, ε_k > 0 with r_k(N) ≤ C_k N exp(−c_k (log N)^{ε_k}) for all N ≥ 2; equivalently an α-dense subset of [N] has a nonconstant k-AP once log N ≥ A_k(2 + log(1/α))^{A_k}. Corollary 1.2: Erdős's reciprocal-sum conjecture (Erdős #3). Prior record for general k: Leng–Sah–Sawhney 2024, r_k(N) ≪ N exp(−(log log N)^{c_k}) — NOT summable over dyadic scales, so #3 was open for every k ≥ 4 (k = 3: Bloom–Sisask 2020). The paper's method: density increments on "triangular polynomial cells" whose precision budgets obey descending recurrences (Theorem 2.1), an absolute increment with dimension-independent fresh rank (Lemma 2.2, via relative lifting App. I), and a return step preserving old determining equations exactly (§7–§9). Two external analytic inputs (§1.5): the LSS quasipolynomial interval inverse theorem [35, Thm 1.2] and Schoen–Sisask radius-sensitive almost-periodicity [43, Thm 5.4].
