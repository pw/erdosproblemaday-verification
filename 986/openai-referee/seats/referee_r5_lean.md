### 1c. Non-vacuity of `ramsey` (sInf)
- `ramsey s t = sInf {n | RamseyProperty s t n}`; if the set were empty, sInf = 0 (Nat). That would make the UPPER bound trivial, but the LOWER bound `t^4/(log t)^{3+ε} ≤ ramsey 5 t` would then be FALSE for large t, so a proof of SharpBounds cannot exploit emptiness. Moreover the Lean proves nonemptiness outright: `SharpRamsey/Bounds/Upper.lean` `ramseyProperty_nonempty` (via `ramseyProperty_pow : RamseyProperty (n+2) t (t^(n+1))`, Erdős–Szekeres-type) and `ramsey_has_property` = `Nat.sInf_mem`. `order_lt_ramsey` (Upper.lean:155) shows `Fintype.card V < ramsey s t` from a K_s-free G with Gᶜ K_t-free, through `ramsey_has_property` + embedding Fin (ramsey) into V; this is the correct direction (needs no monotonicity assumption beyond `property_for_finite_type`).
- `RamseyFive.ramsey` is identified with `SharpLogRamsey.ramsey` (whose second disjunct is `Gᶜ.IsNClique t B`) by `RamseyFive/Bounds/RamseyPropertyRelated.lean:12-21` via Mathlib `isNClique_compl` — a definitional-level rewrite, no content.
- Small t: Real.log 0 = Real.log 1 = 0 and x/0 = 0 in Lean; irrelevant since both statements are "eventually in t" (∃ t₀ / atTop).
