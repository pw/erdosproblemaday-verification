## 3. What EFRS 1978 actually stated (scan https://www.renyi.hu/~p_erdos/1978-18.pdf, pages rendered at 130–150 dpi)
- §7 "QUESTIONS", p. 64 (rendered): "A second problem area concerns the behavior of r(C_m, K_n) as a function of m, when n is fixed. From [3], we know that if m ≥ n²−2, then r(C_m,K_n) = (m − 1)(n − 1) + 1, and so, eventually, the Ramsey number increases montonically with m. We now pose two questions:
  (i) What is the smallest value of m such that r(C_m,K_n) = (m − 1)(n − 1) + 1? It is conjectured that this formula holds for all m ≥ n.
  (ii) What value of m gives the minimum value of r(C_m,K_n)? From the bounds quoted above, we know that if n is fixed, but suitably large, then r(C_m,K_n) > r(C_{2m−1},K_n) and r(C_m,K_n) > r(C_{2m},K_n) for sufficiently small values of m. It is possible at that for a suitably large fixed value of n, r(C_m,K_n) first decreases monotonically, then attains a unique minimum, then increases monotonically with m."
- So EFRS's literal conjecture is "for all m ≥ n", with NO stated (3,3) exception and no stated n ≥ 3 (r(C_3,K_3)=6 ≠ 5 makes the literal statement false at (3,3); n=2 is trivially true). The (3,3) exception / n ≥ 3 appear in later formulations (Bollobás et al. 2000: "for all (n,m) ≠ (3,3) satisfying n ≥ m"; Schiermeyer 2003; KLS 2018). The paper's wording "in the formulation stated by Keevash, Long and Skokan" is therefore ACCURATE and appropriately careful (EXPOSITION-level note: one could add that EFRS's own sentence omits the (3,3) exception).
- The conjecture's "≥" range: EFRS say m ≥ n (rendered glyph ⩾). Bloom's "k≥n≥3 (except when n=k=3)" matches the later formulation. Consistent with the paper's Theorem 1.
- EFRS p. 61 (rendered): "Bondy and Erdős [3] have proved that if m ≥ n² − 2, then r(C_m,K_n) = (m − 1)(n − 1) + 1. In other words, if m is sufficiently large in comparison with n, then the canonical example of n − 1 disjoint copies of K_{m−1} is critical." — a third witness for "≥" in Bondy–Erdős, and the standard lower-bound construction.
- Paper's §1.2 claim "Independent-set expansion and rooted distance layers already appear in … EFRS [Section 3]": EFRS p. 55 (rendered) "Definition. Let l be a natural number. A graph G has property Π_l if, for every independent set X, |Γ(X)| ≥ l|X|." and p. 56 "define A_i = {v | d_H(x, v) = i}. We shall refer to the set A_i as the ith level", with a spanning tree T. CORRECT attribution.
- Bloom's two side-questions vs. source: Bloom "the smallest value of k such that this identity holds (for fixed n)" = EFRS (i) — faithful. Bloom "for fixed n, what is the minimum value of R(C_k,K_n)?" — EFRS (ii) actually asks "What VALUE OF m gives the minimum value" (the minimiser), a slightly different question; Bloom paraphrases loosely.
- Does anyone address them? KLS (Theorems 1.1+1.2) answer both "up to the constant C": "(i) the location of the critical value of ℓ for the transition in behaviour of r(C_ℓ,K_n), and (ii) the choice of ℓ that minimises r(C_ℓ,K_n). The answer to both questions is ℓ = Θ(log n/log log n)." Radziszowski DS1.18 §4.2(c) repeats this, conditionally ("If so, then the results in [KeeLS] … imply that this transition … happens at n = Θ(log m/loglog m)").
- The OpenAI paper does NOT address (i) or (ii) (grep of all sections: no "smallest value", "minimum value", "critical"); its Theorem 1 implies only that for fixed n ≥ 4 the smallest m with the identity is ≤ n (for n = 3 it is m = 4). Known small values (DS1.18 Table Vb) show the smallest such m is < n already for n = 6,7,8 (R(C5,K6)=21=4·5+1, R(C5,K7)=25, R(C5,K8)=29), so question (i) is genuinely NOT settled by the theorem, and "solving #551" on Bloom's page should be read as the displayed statement only.

## 4. Lower-bound construction and the (3,3) exception
- Paper (§1, after Theorem 1.1): "Its lower bound comes from n−1 disjoint red cliques of order m−1, with all edges between them blue." Correct for every m ≥ 3, n ≥ 2: the red graph (n−1)K_{m−1} has components of order m−1 < m, and a cycle is connected, so no red C_m; the blue graph is the complete (n−1)-partite graph K_{m−1,…,m−1}, whose cliques take at most one vertex per part, so no blue K_n. Hence R(C_m,K_n) ≥ (m−1)(n−1)+1. Standard: KLS p. 2 "For any connected graph H, Chvátal and Harary [15] observed that r(H,K_n) ≥ (v(H)−1)(n−1)+1 … red edges consist of n−1 disjoint cliques of order v(H)−1"; EFRS p. 61 "the canonical example of n−1 disjoint copies of K_{m−1}"; Bondy–Erdős p. 47 G(r_1,…,r_t) construction; Nikiforov p. 4 "the disjoint union of r complete graphs of order p is a C_{p+1}-free graph of order rp".
- (3,3): R(C_3,K_3) = R(3,3) = 6 > 5 = formula (witness: red C_5, blue C_5). In the range m ≥ n ≥ 3, m = 3 forces n = 3, so (3,3) is the only m = 3 pair. Every known value with m ≥ n ≥ 3, m ≥ 4 in Radziszowski DS1.18 Table Vb (rendered, p. 28) equals the formula: K3 2n−1; K4 C4..C7 = 10,13,16,19; K5 C5..C9 = 17,21,25,29,33; K6 C6..C9 = 26,31,36,41; K7 C7..C9 = 37,43,49; K8 C8, C9 = 50, 57. No other exception is known in range; failures of the formula occur only for m < n (e.g. R(C3,K4)=9 > 7, R(C4,K5)=14 > 13, R(C4,K6)=18 > 16), consistent with m ≥ n being the conjectured range.
