## 1. Lemma 2.1 and identity (2.2) — re-derived, HOLDS
- Existence: f(t)=t(1−log t) has f'(t)=−log t, max f(1)=1, f→−∞; M_G(w)≥0 on w≥0, so F_G(w) ≤ f(‖w‖∞)+|V|−1 → −∞. The superlevel set {F_G ≥ F_G(0)=0} is compact in [0,∞)^V (F continuous incl. at 0 via 0log0=0) ⇒ max attained. ✓
- Positivity: raising a zero coordinate to t changes F by f(t) − t·w(N(v)) = t(1−log t−w(N(v))) > 0 for small t. ✓ (uses only that the other coordinates are fixed; M changes by exactly t·w(N(v)) because w_v=0).
- (2.1): interior critical point, ∂F/∂w_v = −log w_v − w(N(v)) = 0. Since w(N(v)) ≥ 0, w_v ≤ 1 (=1 iff v isolated). ✓
- (2.2): M(q)=M(w)+Σ_v(q_v−w_v)w(N(v))+M(q−w) (bilinear expansion of the edge form). Substituting w(N(v))=−log w_v, vertex part = w_v − w_v log w_v − q_v + q_v log q_v − (q_v−w_v)log w_v = q_v log(q_v/w_v) − q_v + w_v; q_v=0 gives w_v. ✓ The "0 ≤" is global maximality.
- Concavity/uniqueness: F_G is NOT concave (Hessian = −diag(1/w) − A_G, indefinite in general). Nothing in §2 or §6 assumes uniqueness or concavity: every later statement is "for every maximizer w" (Lemma 2.3, (5.10)) or "let w maximize F_G" (Prop 6.1). **But note**: Lemma 2.3 needs GLOBAL maximality, not stationarity — the comparison vectors q in its proof are far from w (weights on S multiplied by up to 1+e^{4x}b_r). Stationary non-global points can violate (2.5): e.g. on K_{m,k} with m=e^L, k=eL, the stationary point with weight e^{−L} on the m-side and 1/e on the k-side has e_w(S,D)/g_x(w(S)) = L/x with L up to e^x, unbounded; the GLOBAL maximizer there puts ≈1 on the m-side. The paper always uses a global maximizer, so this is not an error — but any reader/formalizer who substitutes "a solution of (2.1)" for "a maximizer" would break Lemma 2.3. (EXPOSITION-level remark only.)

Hand re-derivation (constants as printed, read from optimizer.tex — the PDF display matches the .tex):
- Greedy: the chosen vertex u is NOT removed, only V_i = N(u)∩(remaining); afterwards u has empty neighbourhood in the remaining graph so it is never re-chosen. u ∉ V_i (no loops), u adjacent to all of V_i ⇒ a K_{r−1} in V_i plus u is a K_r ⇒ G[V_i] is K_{r−1}-free. ✓
- (2.4): every v∈R has w(N(v)∩R) ≤ ηs (stopping rule, non-strict), so M_{G[R]} = ½Σ_{v∈R} w_v w(N(v)∩R) ≤ ½ηs·w(R) ≤ ½ηs². ✓ (pdftotext loses the ½'s; the .tex and rendered PDF have them.)
- Law: P(R)=½, P(V_i)=p_i=s_i/(2b), Σp_i=½ ⇒ total 1. ✓ Mean: v∈R: ½·2=1; v∈V_i: p_i·E[m'_v]/p_i = 1; R and the V_i partition V. ✓
- p_i = s_i/(2b) > ηs/(2b) ≥ η/2 = ε/8 because b = Σs_i ≤ s (disjoint) and s_i > ηs (strict). ✓
- Bound: (8/ε)·b_{r−1}(ε/4) = 2^3 ε^{−1}·2^{(r−1)(r−3)}·4^{r−3}ε^{−(r−3)} = 2^{(r−1)(r−3)+2(r−3)+3} ε^{−(r−2)} = 2^{r²−2r} ε^{−(r−2)} = b_r(ε). ✓ And max{2, ·} = b_r(ε) because b_r(ε) ≥ 2^3·2 = 16 for r ≥ 3, ε ≤ ½. ✓ Precision ε/4 ≤ 1/8 ≤ ½, so the IH applies. ✓ The IH is applied to G[V_i] with ITS OWN total weight s_i (right). ✓
- Mass: on R, M_{G[R]}(2w)·½ = 2M_{G[R]}(w); on V_i, p_i·p_i^{−2}·E M_{G[V_i]}(wm') ≤ (ε/4)s_i²/p_i = ε s_i b/2; Σ_i = εb²/2. Cross edges vanish (multipliers 0 outside the chosen set). Total ≤ ηs² + εb²/2 ≤ (¼+½)εs² = ¾εs². ✓ No-parts case: m≡1, E M = M_{G[V]}(w) ≤ ½ηs² = εs²/8. ✓ Base r=2: no edges, m≡1 ≤ b_2 = 1. ✓

## 3. Lemma 2.3 (cross-mass bound, C_r = 16r²) — re-derived, HOLDS
Disjoint case, e^{−x} ≤ s ≤ e^x, t ≤ e^x:
- ε = e^{−8x} ≤ e^{−8} ≤ ½ (x ≥ 1), so Lemma 2.2 applies to G[S] (K_r-free, positive weights, total s). k = e^{4x}, k²ε = 1. ✓
- q − w = k m_v w_v on S, −w_v on D, 0 elsewhere. M_G(q−w) = k² M_{G[S]}(mw) + M_{G[D]}(w) − k Σ_{a∈S,b∈D,ab∈E} m_a w_a w_b. M_{G[D]}(w) ≤ Σ_{a<b} w_a w_b ≤ t²/2 for ANY graph on D. Expectation of the cross term = −k e_w(S,D) (disjoint ⇒ each S–D edge once; only linearity, no independence). ⇒ (2.6). ✓
- Vertex terms of (2.2): 0 off S∪D; w_v on D (sum t); on S, with y = k m_v: w_v[(1+y)log(1+y) − y] ≤ w_v y log(1+y) (⇔ log(1+y) ≤ y) ≤ w_v k m_v log(1 + k b_r); expectation k s log(1+k b_r). ✓
- log(1+k b_r(e^{−8x})) ≤ log(2 k b_r) = (1+r(r−2))log2 + (4+8(r−2))x ≤ A_r x using kb_r ≥ 1 and x ≥ 1. ✓ (checked numerically r=2..199, x ∈ [1,700] in log space; also b-recursion exact for r ≤ 24.)
- 0 ≤ E[F(w)−F(q)] (GLOBAL maximality, pointwise in the realization) ⇒ k e_w ≤ t + kA_r x s + s² + t²/2 ⇒ e_w ≤ A_r x s + e^{−4x}s² + e^{−4x}(t+t²/2). ✓ Error terms /s ≤ e^{−3x}, e^{−2x}, e^{−x}/2 (uses t ≤ e^x, s ≥ e^{−x}); sum ≤ 0.37 ≤ 3x. ✓ And x s ≤ g_x(s) on [e^{−x}, e^x]. ✓
- 0 < s < e^{−x}: x' = log(1/s) > x ≥ 1; s,t ≤ e^x ≤ e^{x'}, s = e^{−x'}, so the case above applies: e_w ≤ (A_r+3)x's ≤ (A_r+3)s(x+x') = (A_r+3)g_x(s). ✓ s = 0: trivial. ✓
- Overlapping S, D: independent fair 2-colouring; P(u ∈ class 1, v ∈ class 2) = ¼ for u ≠ v (no loops) ⇒ E e_w(S',D') = ¼e_w(S,D); w(S') ≤ w(S), w(D') ≤ w(D); g_x monotone (derivative x + log(1/s) − 1 ≥ 0 on (0,1), x on (1,∞), continuous at 0 and 1). ⇒ e_w(S,D) ≤ 4(A_r+3)g_x(s). ✓
- A_r + 3 = 8r − 9 + (r−1)²log2 ≤ 8r − 9 + (r−1)² = r² + 6r − 8 ≤ 4r² (3r² − 6r + 8 > 0 always). ✓ So C_r = 16r², depends only on r. ✓
