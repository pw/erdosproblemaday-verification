# Exact finite value `f(23)=45` for Erdős problem 352

The existing 45-point lower witness passes all 16,215 repeated triples under
the exact squared inequality `(A2-46)^2-4D2>0`, with minimum margin 56.

For the upper bound, normalize a diameter pair to `(0,0),B`; all other points
lie in its finite two-disc lens. Exhausting the no-high and every fixed-high
branch gives 40,791 directly audited proper-coloring certificates. A genuine
avoiding extension is a clique in each compatibility graph, so every proper
coloring is a valid upper bound. All branches are at most 45; exactly
`B=(6,4)` and `B=(6,5)` are tight. Hence `f(23)=45`.

This is a finite computational result in Koizumi's lattice model and does not
establish the uniform linear bound needed for the continuous problem.
