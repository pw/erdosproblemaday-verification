# Exact finite value `f(25)=52` for Erdős problem 352

The existing 52-point lower witness passes all 24,804 repeated triples under
the exact squared inequality `(A2-50)^2-4D2>0`, with minimum margin 25.

For the upper bound, normalize a diameter pair to `(0,0),B`; all other points
lie in its finite two-disc lens. Exhausting the no-high and every fixed-high
branch gives 58,925 directly audited proper-coloring certificates. A genuine
avoiding extension is a clique in each compatibility graph, so every proper
coloring is a valid upper bound. All branches are at most 52, uniquely tight
at `B=(7,3)`. Hence `f(25)=52`.

This is a finite computational result in Koizumi's lattice model and does not
establish the uniform linear bound needed for the continuous problem.
