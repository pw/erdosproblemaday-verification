THEOREM 1.1. There are absolute constants C and 1 ≤ β < 4/3 with u(n) ≤ C n^β, where u(n) = max over n-point planar sets of the number of unordered unit-distance pairs. I.e. u(n) = O(n^{4/3−δ}) for some absolute δ > 0 — a power saving over Spencer–Szemerédi–Trotter 1984. δ is NOT made explicit (the proof is by contradiction along a sequence, with ultraproducts).
