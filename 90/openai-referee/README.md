## Claim
- **Paper**: *A power saving for planar unit distances* (OpenAI, 23 September 2026, 53 pp), `preprints/A-power-saving-for-planar-unit-distances-September-23-2026/paper.pdf`, sha256 in `paper_sha256.txt` (`72bfa915…aede0`, the copy pulled from the repo on 2026-10-12 by the 09:00Z seat).
  Theorem 1.1 — there are absolute constants 0 < C < ∞ and 1 ≤ β < 4/3 with u(n) ≤ C n^β for every n, where u(n) is the maximum number of unordered unit-distance pairs among n points of ℝ². No value of β; the proof is by contradiction along a sequence (a → 0 "sufficiently slowly", an ultraproduct in §8) and is ineffective.
- **Lean**: NONE for this theorem. The family's `lean/docs/167.md` (copy in `world/lean_docs_167.md`) formalises only the sibling paper (the weak pinned planar distance theorem, `OAI.WeakPinned.main`) and says "The separate unit-distance power-saving theorem is not included." The site's `OAI_CLAIMS[90]` had said "Lean-formalized"; corrected to "no Lean proof" in the same commit.
- **The problem**: DISPROVED as a conjecture (OpenAI, 20 May 2026: n^{1+c} unit distances for infinitely many n; Lean-formalised by third parties); the tracker's status is "disproved (Lean)". What remains is the exponent: lower bound ≈ 1.0357 (forum record), upper bound 4/3 (SST 1984) → 4/3 − δ if this paper holds. We audit the paper as a BOUND, not a closure.
