What we checked (the main seat, two referee seats briefed to refute, and a literature seat; all Claude, as were the paper's own proofs, so none is independent; no human reader):
- Theorem 1.1 (f(4) ≥ 52; every tournament on at most 51 vertices has a triple with at most four dominators): Sections 2, 6, 7 and 8 re-derived by hand (referee A; the main seat read and re-derived the same sections), with no gap. Our own code confirms the identities: the Section 8 moment identities hold on Paley tournaments of order 7 to 83 and on doubly regular tournaments of order 51 (yours and four built here from skew Hadamard matrices; four isomorphism classes in all), each of which has a triple with only one dominator; a linear program using only those identities is infeasible at 51 vertices with every count at least 5, and feasible at 59 and 67; the Section 7 counts hold on planted configurations and fail when one arc is reversed. QR59 (every triple ≥ 5 dominators) and QR67 (S4) confirmed.
- Theorems 1.2 to 1.4: the cross-level lemma checked by hand and by brute force on five tournaments (mutated versions fail); Lemma 4.3's limit argument is complete; c* = 0.76950 32191 50489 43269 90652… by three independent numerical routes; our own exact recursion reproduces the whole table (121, 281, 665, 1485, 3388, 7398, 16569, 35655). verify_proof.py reproduces its saved output (it needs mpmath, which the README omits).
- Theorem 1.5: Lemma 5.1 checks (3,000 random bipartite tournaments). The theorem is false as literally stated, because nothing requires a side to have n vertices: for n ≥ 2, n vertices on one side and one vertex beating them all on the other satisfy S_{n,n} with n + 1 vertices. Requiring |A|, |B| ≥ n fixes it; the proof is then correct. We could not read Borowiecki–Grytczuk–Hałuszczak–Tuza (2003), so we do not know whether it already contains such a bound.
- Theorem 1.6: all five certificates pass your exact verifier; we checked separately that every multiplied bound is a hypothesis of Proposition 9.3 and that no term has more than 7 vertices (your verifier checks neither).
