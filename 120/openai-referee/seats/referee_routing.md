## 1. Objections (numbered)

### O1. Lemma 4.3 assumes a stable center, but never uses it — COSMETIC
- **Location:** §4.3, Lemma 4.3, PDF p. 9. The statement reads: "Fix a stable center x and an atom ξ of F_x on which the first default vertex U exists."
- **What is wrong:** Nothing is false. The proof of (4.6) uses only three things: Lemma 3.3 (which "holds at every center", p. 6), the product structure, and F_x ⊆ 𝒜. Stability enters the argument only through Lemma 4.2, i.e. through the inclusion "miss ⇒ all local tests fail" in §5.
- **Checked numerically:** with g = 1, every center is unstable (see §4 below: all 11 noninitial windows fail). At such centers (4.6) still matched to |z| ≤ 1.6 in 16 cells, and the success count matched Bin((M−1)r, p/2) (χ² p ≥ 0.13). At the same unstable centers, Lemma 4.2 fails tens of thousands of times. So the two lemmas really do rest on different hypotheses.
- **Fix:** drop "stable" from Lemma 4.3. The dyadic paper carries the same superfluous hypothesis through its standing assumption: "Fix henceforth a stable center x ∈ G" (dyadic §4.3, p. 8).

### O2. "Exact" is true for the stated event; the downstream use needs only "≤" — COSMETIC (no gap)
- **Location:** §4.3 title "The exact failure probability at a fixed scale" and (4.6), p. 9. Downstream, p. 10: "P(∃t ∈ [1, 2] ∀n ∈ N : x + tq^n ∉ B | ξ) ≤ |T_{x,ξ}|(1 − p/2)^{(M−1)r}".
- **Assessment:**
  - (4.6) is an exact equality for the event "all (M−1)r local tests fail". It is in fact a corollary of something stronger, which the simulation confirms: conditional on ξ, the indicators Q_i(y_n(t)) are i.i.d. Bernoulli(p/2). Given the selector field 𝒜, Q = A·V with V i.i.d. Bernoulli(p) at distinct 𝒜-measurable addresses, and given ξ the A's are i.i.d. fair bits.
  - The quantity that matters later — a miss — is only bounded by it. Lemma 4.2 gives only the one-way implication Q_i(y) = 1 ⇒ y ∈ B (4.5), so {miss at t} ⊆ {all Q fail at t}.
  - §5 uses (4.6) only as an upper bound, which is all it needs. The paper never claims an exact miss probability, so nothing is mislabelled.
- **Fix:** none needed.

### O3. Off-route exposed entries below U: the proof neither needs them fresh nor says so — COSMETIC (exposition)
- **Location:** §4.2, p. 8: "For a fixed center x ∈ R, expose its addressed entry in every selector table, including tables outside its route." Also Lemma 4.3, p. 9: "Next condition on 𝒜, the sigma-field of all selectors."
- **The worry (brief ii):** a translated point y_n(t), routed below U_i, might read x's exposed entry in a subtree table.
- **Why it cannot happen:** every selector edge f strictly below U_i comes after e_i in preorder, so b_f > b_{e_i}. The second sentence of Lemma 3.3 ("They also have pairwise distinct keys under every J_b with b ≥ b_e") then gives J_{b_f}(y_n(t)) ≠ J_{b_f}(x). Verified deterministically: `sub_reads_exposed = 0` in every structural check, including at unstable centers.
- **Why it would not matter anyway:** Lemma 4.3 conditions on all of 𝒜. The subtree selectors affect only which leaf L_{i,n} is read. The conditional failure probability (1 − p)^{ΣA} depends only on the A_{i,n}, and their law given ξ is established separately: they read distinct unexposed coordinates of the tables S_{e_i}.
- **Fix:** an optional sentence pre-empting the question. No mathematical content is missing.

### O4. Notation clash between 𝒜 and A_{i,n} — COSMETIC
- **Location:** p. 7: "Write 𝒜 for the sigma-field generated by all entries of all selector tables". p. 9: "For each pair put A_{i,n} = S_{e_i}(J_{b_{e_i}}(y_n(t)))".
- In the PDF, calligraphic 𝒜 and italic A sit side by side in "P(… | 𝒜) = (1 − p)^{Σ A_{i,n}}". It reads correctly in the rendered PDF but is lost in any plain-text rendering. The dyadic paper uses 𝒮 for the sigma-field and avoids the clash.

### O5. Two dyadic sentences missing from the geometric version — COSMETIC
The geometric version omits two clarifying sentences that the dyadic version has:
- In dyadic Lemma 4.2's proof (p. 9): "Later sibling selectors at an ancestor are not needed to make its choice."
- In dyadic Lemma 4.3's proof (p. 10–11): "This proves the claim, even for pairs with A_{i,n} = 0." and "The empty-success case has exponent zero and probability one."

The geometric proofs are still complete:
- Geometric Lemma 4.2 says explicitly "The decision at P reads zeros at indices less than a and one at a", so only edges (P, j) with j ≤ a are involved, and all of them precede e_i.
- The κ-distinctness argument in geometric Lemma 4.3 never uses A_{i,n} = 1.

**Not a step missing in the geometric paper** (see §5 below).

### Note (not an objection to the paper): the brief's toy parameter g = 1 admits NO stable center
With M = 3, d = 2, g = 1, every window's stability interval (x, x + 2q^{a_e}] is at least as long as the lattice spacing 1/N_{b'}:
- q = 1/2: 2N_{b'}q^{a_e} = 2·2^{b'+3}·2^{−(b'+2)} = 4 exactly.
- q = 1/3: 2N_{b'}q^{a_e} ≥ 2c q^{g+1} = 12/9; minimum observed 1.386.

So every x fails every noninitial window's condition (observed 11/11 for random x). This is consistent with the paper:
- Lemma 3.2's bound 4Kcq^{g+1} (= 96, resp. 32) is then vacuous.
- §5 chooses g with 4Kcq^{g+1} < p, which forces 2N_{b'}q^{a_e} < 4cq^{g+1} < 1 for every window. That makes every lattice point, x = 0 included, stable.

For the stable-center experiments I used g = 4 (q = 1/2), g = 3 (q = 1/3) and g = 60 (q = 9/10, c = 40); M = 3, d = 2, r_0 = 2 throughout. The g = 1 runs were kept for two purposes: the stability-free part, (4.6), and as a live negative control for Lemma 4.2.

## 3. The specific questions of the brief, answered

**(iii) Preorder / Lemma 4.2.**
- **Edges consulted on the way to U.** At a strict ancestor P of U, x chooses child a < M because U is the first default vertex. Both x and y_n(t) read exactly (P, 1), …, (P, a). Each precedes e_i in preorder: (P, j) with j < a comes before (P, a), and (P, a) comes before the whole block of P_a's subtree, which contains U and hence e_i.
- **Rejected siblings at U.** For j < i, (U, j) and its subtree come before (U, i).
- **(3.3) covers them.**
  - (3.3) is stated for every edge f preceding e. It needs only stability of x for the single window W_{e_i}, whose predecessor endpoint b′ is the endpoint of the immediately preceding window in the global preorder list.
  - Windows are laid in preorder with a_e = b′ + g + 1 > b′, so endpoints strictly increase along preorder and b_f ≤ b′ for every preceding f.
  - (x, x + tq^n] ⊆ (x, x + 2q^{a_e}] for n ≥ a_e and t ≤ 2. The cell convention puts a boundary at x into x's own cell, and integers are lattice points, so a wrap is excluded.
  - Nesting then gives (3.3).
- **Deterministic checks (exact rationals):**
  - `order_viol = 0` for every (U, i, edge consulted).
  - (3.3) holds at stable centers with 0 violations over 1,296 / 1,152 / 9,360 (e, n, t, f) quadruples. At unstable centers it shows 113 / 77 violations — the negative control.
  - Lemma 4.2's conclusion (route reaches U and reads/rejects (U, 1..i−1)) and implication (4.5) held on every sample at stable centers. Over all 48 stable-center cells that was 0 violations in 26,880,000 translated-point root routings, including 5,373,778 successes Q = 1.
  - At unstable centers (g = 1, U = (2,)) the same check reports 30,000–45,000 route violations and 3,000–5,500 implication violations per 20,000 samples. The instrument is live.

**(ii) Lemma 4.3.**
- **A_{i,n} distinctness.**
  - Within table e_i, Lemma 3.3 gives pairwise distinct keys for {x} ∪ {y_n(t) : n ∈ W_{e_i}} at b_{e_i}: distances ≥ (1 − q)q^b > q^b/c ≥ 1/N_b inside an interval of length ≤ 2q^{n_0} ≤ 1/4.
  - So the A_{i,n} are pairwise distinct coordinates and avoid the one entry of S_{e_i} that ξ exposes. Different i means different tables.
  - The other exposed entries (one per table, on or off x's route) are in tables the A_{i,n} do not read. The A_{i,n} are therefore distinct unexposed coordinates, hence i.i.d. fair given ξ.
  - Deterministic: `A_dup = 0`, `A_hits_exposed = 0` in all cells, including grid-boundary scales t. Mutating c → c/64 produces `A_dup = 2`, `A_hits_exposed = 2` — the negative control.
- **κ distinctness for every realization.**
  - The three cases are complete: different i means different child subtrees, hence different terminal tables. Same i but different leaf means a different table. Same leaf L means b(L) ≥ b_{e_i}, because L's incoming edge is e_i or comes later in preorder, so the endpoint is larger; nesting preserves the distinct b_{e_i} keys.
  - Checked for every realization at once, deterministically: for every leaf L below every U_i, b(L) ≥ b_{e_i} and J_{b(L)}(y_n) is injective in n (`bL_lt = 0`, `kappa_dup = 0`). It also never failed on any sample.
- **Conditioning order.**
  - σ(ξ) ⊆ F_x ⊆ 𝒜 and the terminal tables are independent of 𝒜. The κ's are 𝒜-measurable and distinct, so given 𝒜 the terminal bits there are i.i.d. Bernoulli(p), and P(all fail | 𝒜) = (1 − p)^{ΣA}.
  - The tower property gives P(· | ξ) = E[(1 − p)^{ΣA} | ξ] = ∏(1/2 + (1 − p)/2), because the A_{i,n} are i.i.d. fair given ξ.
  - All steps are exact. The routing selectors below U never need to be fresh (O3).

**Lemma 4.1 (brief i).** Exact, and B is a finite union of half-open cells per period (table above). The density is p no matter how deep the tree or how fine the grids. Deepening the tree adds routing resolution, never measure, because the leaf-reading terminal table is independent of all selectors. This is the claimed mechanism and it is correct.

#!/usr/bin/env python3
"""Toy build of the routing construction of Section 4 of
'The geometric case of the Erdos similarity conjecture' (OpenAI, 5 Oct 2026),
exact rational arithmetic for all grid keys, lazily-sampled (hence exactly
distributed) independent tables.  Checks: Lemma 3.1, (3.3), Lemma 3.3 at the
addresses Lemma 4.3 uses, (4.3), Lemma 4.1, Lemma 4.2, Lemma 4.3 / (4.6).

import sys, math, random
from fractions import Fraction as F

# ---------------------------------------------------------------- construction
class Construction:
    def __init__(self, q, M, d, g, r0, cscale=F(1)):
        self.q, self.M, self.d, self.g, self.r0 = q, M, d, g, r0
        self.c = F(4) / (1 - q) * cscale          # cscale != 1 only in the mutation control
        def pre(P):
            out = []
            for i in range(1, M + 1):
                out.append((P, i))
                if len(P) + 1 < d:
                    out += pre(P + (i,))
            return out
        self.edges = pre(())
        self.pos = {e: k for k, e in enumerate(self.edges)}
        self.K = len(self.edges)
        r = {1: r0}; sig = {1: M * r0 + (M - 1) * g}
        for h in range(2, d + 1):
            r[h] = max(r0, g + sig[h - 1])
            sig[h] = M * (r[h] + g + sig[h - 1]) + (M - 1) * g
        self.r, self.sig = r, sig
        n0 = 1
        while 2 * q ** n0 > F(1, 4):
            n0 += 1
        self.n0 = n0
        self.W = {}
        a = n0
        for e in self.edges:
            h = d - len(e[0])
            self.W[e] = (a, a + r[h] - 1)
            a = a + r[h] + g                       # g unused indices, next a = b + g + 1
        self.bstar = {}
        for e in self.edges:
            child = e[0] + (e[1],)
            sub = [f for f in self.edges if f[0][:len(child)] == child]
            self.bstar[e] = max([self.W[e][1]] + [self.W[f][1] for f in sub])
        self.Nc = {}
        self.ends = sorted(set(self.W[e][1] for e in self.edges))

    def height(self, e):
        return self.d - len(e[0])

    def sel_edges(self):
        return [e for e in self.edges if e[1] < self.M]

    def N(self, b):
        if b not in self.Nc:
            v = self.c / self.q ** b
            k = max(0, v.numerator.bit_length() - v.denominator.bit_length() - 2)
            while (1 << k) < v:
                k += 1
            self.Nc[b] = 1 << k
        return self.Nc[b]

    def J(self, b, z):
        fz = z - math.floor(z)
        return math.floor(self.N(b) * fz)

    def bL(self, L):
        return self.W[(L[:-1], L[-1])][1]

    def leaves_below(self, v):
        if len(v) == self.d:
            return [v]
        out = []
        for i in range(1, self.M + 1):
            out += self.leaves_below(v + (i,))
        return out

    def stable(self, x):
        """paper's definition: (x, x+2q^{a_e}] n Gamma_{b'} empty for every noninitial window"""
        bad = []
        for k in range(1, self.K):
            e, prev = self.edges[k], self.edges[k - 1]
            bp = self.W[prev][1]; a = self.W[e][0]; Nb = self.N(bp)
            if math.floor(Nb * (x + 2 * self.q ** a)) - math.floor(Nb * x) != 0:
                bad.append(e)
        return bad

# ---------------------------------------------------------------- one outcome
class Outcome:
    """independent tables, entries drawn on first read (exactly the product law)"""
    def __init__(self, rng, p, exposed):
        self.rng, self.p = rng, p
        self.S = dict(exposed)
        self.T = {}
        self.Sreads = []
    def s(self, e, key):
        k = (e, key)
        v = self.S.get(k)
        if v is None:
            v = 1 if self.rng.random() < 0.5 else 0
            self.S[k] = v
        return v
    def t(self, L, key):
        k = (L, key)
        v = self.T.get(k)
        if v is None:
            v = 1 if self.rng.random() < self.p else 0
            self.T[k] = v
        return v

def route(C, om, start, keys):
    """keys: dict endpoint b -> J_b(z).  Returns (leaf, trace[(vertex, edge, bit)])"""
    P = start; trace = []
    while len(P) < C.d:
        chosen = C.M
        for i in range(1, C.M):
            e = (P, i)
            bit = om.s(e, keys[C.W[e][1]])
            trace.append((P, e, bit))
            if bit == 1:
                chosen = i
                break
        P = P + (chosen,)
    return P, trace

def keys_of(C, z):
    return {b: C.J(b, z) for b in C.ends}

# ---------------------------------------------------------------- stats
def binom_pmf(n, k, s):
    return math.comb(n, k) * s ** k * (1 - s) ** (n - k)

def chi2_sf(x, k):
    # regularized upper incomplete gamma Q(k/2, x/2)
    a, xx = k / 2.0, x / 2.0
    if xx <= 0: return 1.0
    if xx < a + 1:
        term = 1.0 / a; s = term; n = 1
        while abs(term) > 1e-15 * abs(s):
            term *= xx / (a + n); s += term; n += 1
        return 1.0 - s * math.exp(-xx + a * math.log(xx) - math.lgamma(a))
    b = xx + 1 - a; cc = 1e300; dd = 1 / b; h = dd
    for i in range(1, 10000):
        an = -i * (i - a); b += 2
        dd = an * dd + b; dd = 1e-300 if abs(dd) < 1e-300 else dd
        cc = b + an / cc; cc = 1e-300 if abs(cc) < 1e-300 else cc
        dd = 1 / dd; de = dd * cc; h *= de
        if abs(de - 1) < 1e-15: break
    return math.exp(-xx + a * math.log(xx) - math.lgamma(a)) * h

def chi2_binom(counts, n, s, total):
    exp = [total * binom_pmf(n, k, s) for k in range(n + 1)]
    # pool tail bins until expected >= 5
    bins = []; o = e_ = 0.0
    for k in range(n + 1):
        o += counts.get(k, 0); e_ += exp[k]
        if e_ >= 5:
            bins.append((o, e_)); o = e_ = 0.0
    if bins and e_ > 0:
        lo, le = bins.pop(); bins.append((lo + o, le + e_))
    stat = sum((o - e) ** 2 / e for o, e in bins)
    dof = max(1, len(bins) - 1)
    return stat, dof, chi2_sf(stat, dof)

    worst = 0
    for e in C.edges:
        h = C.height(e)
        span = C.bstar[e] - C.W[e][0] + 1
        if span > 2 * C.r[h]: ok = False; out.append(f"Lemma3.1 violated at {e}: {span} > {2*C.r[h]}")
        worst = max(worst, F(span, 2 * C.r[h]))
    out.append(f"[{label}] windows: n0={C.n0} r={C.r} sigma={C.sig} K={C.K} last index={C.W[C.edges[-1]][1]}; "
               f"Lemma 3.1 max span/(2r_h) = {float(worst):.3f}")
    # every lattice/edge resolution: N_b nondecreasing, powers of 2
    Ns = [C.N(b) for b in C.ends]
    if any(Ns[i] > Ns[i + 1] for i in range(len(Ns) - 1)): ok = False; out.append("N_b not monotone")
    bad = C.stable(x)
    out.append(f"[{label}] x={x} stable? {not bad} (failing windows: {len(bad)}/{C.K-1})")
    # (3.3) for every e, n in W_e, t in tlist, f preceding e
    v33 = 0; n33 = 0
    kx = keys_of(C, x)
    for k, e in enumerate(C.edges):
        for n in range(C.W[e][0], C.W[e][1] + 1):
            for t in tlist:
                ky = keys_of(C, x + t * C.q ** n)
                for f in C.edges[:k]:
                    n33 += 1
                    if ky[C.W[f][1]] != kx[C.W[f][1]]: v33 += 1
    out.append(f"[{label}] (3.3) checks: {n33}, violations: {v33}")
    # Lemma 3.3 at b_e and at every finer used resolution
    v34 = 0; n34 = 0
    for e in C.edges:
        for t in tlist:
            pts = [x] + [x + t * C.q ** n for n in range(C.W[e][0], C.W[e][1] + 1)]
            for b in [bb for bb in C.ends if bb >= C.W[e][1]]:
                ks = [C.J(b, z) for z in pts]
                n34 += 1
                if len(set(ks)) != len(ks): v34 += 1
    out.append(f"[{label}] Lemma 3.3 (all edges, all finer used b, all t): {n34} key-sets, collisions: {v34}")
    return ok and v33 == 0 and v34 == 0, out

def lemma43_structure(C, x, U, t):
    """Deterministic, covers EVERY realization of the selectors:
    (a) A_{i,n} addresses pairwise distinct and != exposed address in e_i's table;
    (b) for every leaf L below U_i, b(L) >= b_{e_i} and J_{b(L)}(y_n) pairwise distinct over n;
    (c) no selector table f strictly below U_i is read by any y_n at x's exposed address;
    (d) every edge read on x's route to U and (U,j), j<i, precedes e_i in preorder."""
    res = {"A_dup": 0, "A_hits_exposed": 0, "bL_lt": 0, "kappa_dup": 0, "sub_reads_exposed": 0,
           "order_viol": 0, "checked_leaves": 0}
    kx = keys_of(C, x)
    # x's route edges up to U (all exposed reads), from the exposure itself
    path_edges = []
    P = ()
    while P != U:
        a = U[len(P)]
        path_edges += [(P, j) for j in range(1, a + 1) if j < C.M]   # reads 1..a (a<M on the way to U)
        P = P + (a,)
    for i in range(1, C.M):
        ei = (U, i); be = C.W[ei][1]
        ys = [x + t * C.q ** n for n in range(C.W[ei][0], C.W[ei][1] + 1)]
        ka = [C.J(be, y) for y in ys]
        if len(set(ka)) != len(ka): res["A_dup"] += 1
        if kx[be] in ka: res["A_hits_exposed"] += 1
        Ui = U + (i,)
        for L in C.leaves_below(Ui):
            res["checked_leaves"] += 1
            if C.bL(L) < be: res["bL_lt"] += 1
            kk = [C.J(C.bL(L), y) for y in ys]
            if len(set(kk)) != len(kk): res["kappa_dup"] += 1
        for f in C.sel_edges():
            if f[0][:len(Ui)] == Ui:
                bf = C.W[f][1]
                if any(C.J(bf, y) == kx[bf] for y in ys): res["sub_reads_exposed"] += 1
        for f in path_edges + [(U, j) for j in range(1, i)]:
            if not C.pos[f] < C.pos[ei]: res["order_viol"] += 1
    return res

# ---------------------------------------------------------------- Monte Carlo pieces
def make_atom(C, x, U, rng):
    """an atom xi of F_x whose first default vertex is U; off-route exposures random"""
    exp = {}
    for e in C.sel_edges():
        exp[(e, C.J(C.W[e][1], x))] = rng.randint(0, 1)
    P = ()
    while P != U:
        a = U[len(P)]
        for j in range(1, C.M):
            k = (((P), j), C.J(C.W[(P, j)][1], x))
            exp[k] = 1 if j == a else (0 if j < a else exp[k])
        P = P + (a,)
    for j in range(1, C.M):
        exp[((U, j), C.J(C.W[(U, j)][1], x))] = 0
    # sanity: route x under exposure alone, find first default
    om = Outcome(random.Random(0), 0.5, exp)
    kx = keys_of(C, x)
    P = (); first = None
    before = len(om.S)
    while len(P) < C.d:
        ch = C.M
        for i in range(1, C.M):
            if om.s((P, i), kx[C.W[(P, i)][1]]) == 1:
                ch = i; break
        if ch == C.M and first is None: first = P
        P = P + (ch,)
    assert len(om.S) == before, "route of x read an unexposed entry"
    assert first == U, (first, U)
    return exp

def mc_lemma43(C, x, U, exp, t, p, nsamp, seed):
    rng = random.Random(seed)
    h = C.height((U, 1)); r = C.r[h]
    pairs = []
    for i in range(1, C.M):
        ei = (U, i)
        for n in range(C.W[ei][0], C.W[ei][1] + 1):
            y = x + t * C.q ** n
            pairs.append((i, n, keys_of(C, y)))
    npairs = len(pairs)
    assert npairs == (C.M - 1) * r
    allfail = 0; counts = {}; v42_route = 0; v42_impl = 0; q1 = 0; kdup = 0
    for _ in range(nsamp):
        om = Outcome(rng, p, exp)
        succ = 0; kappas = set()
        for (i, n, ky) in pairs:
            ei = (U, i)
            A = om.s(ei, ky[C.W[ei][1]])
            Ui = U + (i,)
            if len(Ui) == C.d:
                L = Ui
            else:
                L, _ = route(C, om, Ui, ky)
            kap = (L, ky[C.bL(L)])
            if kap in kappas: kdup += 1
            kappas.add(kap)
            V = om.t(L, ky[C.bL(L)])
            Q = A * V
            succ += Q
            # Lemma 4.2: actual root route of y_n(t)
            leaf, trace = route(C, om, (), ky)
            visited = {v for (v, _, _) in trace}
            reachedU = (U == () or U in visited) and leaf[:len(U)] == U
            rej_ok = all(bit == 0 for (v, e, bit) in trace if v == U and e[1] < i)
            # and it actually read (U,j) for all j<i (did not leave U earlier)
            readj = {e[1] for (v, e, bit) in trace if v == U}
            if not (reachedU and rej_ok and all(j in readj for j in range(1, i))):
                v42_route += 1
            if Q == 1:
                q1 += 1
                inB = om.t(leaf, ky[C.bL(leaf)]) == 1
                if not inB: v42_impl += 1
        counts[succ] = counts.get(succ, 0) + 1
        if succ == 0: allfail += 1
    pred = (1 - p / 2) ** npairs
    est = allfail / nsamp
    se = math.sqrt(pred * (1 - pred) / nsamp)
    stat, dof, pv = chi2_binom(counts, npairs, p / 2, nsamp)
    return dict(npairs=npairs, est=est, pred=pred, z=(est - pred) / se if se > 0 else float('nan'),
                chi2=stat, dof=dof, pval=pv, v42_route=v42_route, v42_impl=v42_impl, q1=q1, kdup=kdup)

def mc_density(C, p, nsamp, seed, zfixed=None, mutate=False):
    rng = random.Random(seed)
    bmax = max(C.ends); kmax = C.N(bmax).bit_length() - 1
    KB = kmax + 40
    hits = 0
    for _ in range(nsamp):
        om = Outcome(rng, p, {})
        if zfixed is None:
            Z = rng.getrandbits(KB)
            ky = {b: Z >> (KB - (C.N(b).bit_length() - 1)) for b in C.ends}
        else:
            ky = zfixed
        leaf, trace = route(C, om, (), ky)
        if mutate:   # control: membership read from the last SELECTOR bit (correlated with routing)
            hits += 1 if (trace[-1][2] == 1 or om.t(leaf, ky[C.bL(leaf)]) == 1) else 0
        else:
            hits += om.t(leaf, ky[C.bL(leaf)])
    est = hits / nsamp
    return est, (est - p) / math.sqrt(p * (1 - p) / nsamp)

def mc_nodefault(C, x, nsamp, seed):
    rng = random.Random(seed)
    kx = keys_of(C, x); nod = 0
    for _ in range(nsamp):
        om = Outcome(rng, 0.5, {})
        leaf, trace = route(C, om, (), kx)
        if all(c != C.M for c in leaf): nod += 1
    pred = (1 - 2 ** (1 - C.M)) ** C.d
    est = nod / nsamp
    return est, pred, (est - pred) / math.sqrt(pred * (1 - pred) / nsamp)

def find_stable(C, rng, bits, tries=200000):
    for _ in range(tries):
        x = F(rng.getrandbits(bits), 1 << bits)
        if not C.stable(x): return x
    return None

def boundary_t(C, x, U, rng):
    """a t in [1,2] at which some y_n(t) is exactly a lattice point of Gamma_{b_{e_1}}"""
    e = (U, 1); n = C.W[e][1]; b = C.W[e][1]; Nb = C.N(b)
    lo = math.ceil(Nb * (x + C.q ** n)); hi = math.floor(Nb * (x + 2 * C.q ** n))
    k = rng.randint(lo, hi)
    t = (F(k, Nb) - x) / C.q ** n
    assert 1 <= t <= 2 and C.J(b, x + t * C.q ** n) * 1 == k % Nb
    return t
